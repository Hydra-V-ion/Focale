# Focale
<small>I vibecoded Focale just for me, but if you want to use it, feel free.</small>

## How it works

Every week, you can spin the wheel and see what project/idea/... you will work for this week. You can add your projects, and also quests for small projects/ideas/... you need to do every day.

The application work on a day streak.
